Device configuration for Xiaomi Mi 15 Pro
=========================================

The Xiaomi Mi 15 Pro (codenamed _"haotian"_) is a flagship smartphone from Xiaomi.

It was released in October 2024.

## Device specifications

| Basic | Spec Sheet |
| :----- | :--------- |
| SoC | Qualcomm Snapdragon® 8 Elite Mobile Platform |
| CPU | Octa-core (2×4.32 GHz + 6×3.53 GHz) |
| GPU | Adreno™ 830 |
| Memory | 12/16 GB LPDDR5X |
| Storage | 256/512 GB, 1 TB (UFS 4.0) |
| Shipped Android Version | Android 15, HyperOS 2 |
| Battery | 6100 mAh |
| Charging | 90W wired / 50W wireless / 10W reverse wireless |
| Dimensions | 161.3 × 75.3 × 8.35 mm |
| Display | 6.73" LTPO AMOLED, 3200×1440, 1–120 Hz |
| Rear Camera | 50 MP (wide) + 50 MP (ultrawide) + 50 MP (5× periscope) |
| Front Camera | 32 MP |
